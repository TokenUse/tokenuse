# TokenUse CLI

Track and analyze Claude Code usage.

## Installation

### Homebrew (macOS/Linux)

```bash
brew tap tokenuse/tap
brew install tokenuse
```

### npm/npx

```bash
npx tokenuse@latest
# or
npm install -g tokenuse@latest
# verify
tokenuse version
```

### curl (macOS/Linux)

```bash
curl -fsSL https://get.tokenuse.ai | bash
```

## Usage

```bash
# Login and start tracking
tokenuse login

# Check status
tokenuse status

# Sign out
tokenuse logout
```
